# フェーズ1: スクリーンショット自動取得

## 概要
Kindle for Macアプリから本のページを自動的にスクリーンショット撮影し、連番付き画像ファイルとして保存するシステム。

## 前提条件
### 必須要件
1. **Kindle for Macアプリ**
   - App StoreまたはAmazon公式サイトからインストール
   - Amazonアカウントでログイン済み
   - 対象の本が購入済みまたはKindle Unlimitedで利用可能

2. **macOSの設定**
   - システム環境設定 > セキュリティとプライバシー > プライバシー > アクセシビリティ
   - ターミナルまたはPythonにチェックを入れる（スクリーンショット取得のため）

3. **本の準備**
   - Kindleアプリで対象の本を開いておく
   - 最初のページ（キャプチャ開始位置）を表示
   - フルスクリーンモードは解除（ウィンドウモードで使用）

### 動作環境
- macOS 10.14以降推奨
- Python 3.7以上
- 十分なストレージ容量（1ページあたり約1-2MB）

## セットアップ
```bash
# 必要なライブラリのインストール
pip install pyautogui pillow

# macOSでpyautoguiを使う場合の追加設定
# Homebrewがインストール済みの場合
brew install python-tk
```

## 使用方法
### 必須引数
- `--book`: 本の名前（出力フォルダ名に使用）

### オプション引数
- `--pages`: キャプチャするページ数（デフォルト: 10）
- `--start`: 開始ページ番号（デフォルト: 1）
- `--end`: 終了ページ番号（--pagesより優先）

### 実行例
```bash
# 基本実行（10ページ分）
python capture.py --book "Python入門"

# 100ページ分キャプチャ
python capture.py --book "Python入門" --pages 100

# 50ページ目から150ページ目まで
python capture.py --book "Python入門" --start 50 --end 150
```

## 設定
`config.json`で以下の項目を設定できます：
- `capture_area`: スクリーンショットの撮影範囲
  - `x`, `y`: 開始位置
  - `width`, `height`: キャプチャサイズ
- `page_turn_delay`: ページめくりの待機時間（秒）
- `output_format`: 画像フォーマット（png/jpg）
- `max_pages`: 最大ページ数制限

## 出力
- 画像ファイルは `output/[book_name]/` フォルダに保存
- ファイル名: `page_001.png`, `page_002.png`, ...

## トラブルシューティング
### よくある問題
1. **「アクセシビリティ権限がありません」エラー**
   - システム環境設定でPythonまたはターミナルに権限を付与

2. **ページめくりが動作しない**
   - Kindleアプリがアクティブウィンドウか確認
   - `page_turn_delay`を長めに設定（3.0秒など）

3. **画像が真っ黒になる**
   - `capture_area`の座標を調整
   - Kindleアプリの位置を確認

## 注意事項
- キャプチャ中はマウスやキーボードを操作しないでください
- 大量のページをキャプチャする場合は、定期的に休憩を入れることを推奨
- 著作権法を遵守し、個人利用の範囲でご使用ください
